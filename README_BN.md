# আমার WhatsApp AI সহকারী: চালু করার গাইড

## ধাপ ১: GitHub-এ ফাইল তোলা
1. github.com-এ **New repository** চাপুন। নাম `wa-assistant`, **Private** রাখুন, Create করুন।
2. **uploading an existing file** লিংকে চাপুন।
3. জিপ খুলে ভেতরের সব ফাইল ও `public` ফোল্ডার টেনে ছেড়ে দিন, তারপর **Commit changes** চাপুন।

## ধাপ ২: Railway-তে চালু করা
1. railway.com → **New Project → Deploy from GitHub repo** → `wa-assistant` বাছুন।
2. সার্ভিসে চাপুন → **Variables** → যোগ করুন:
   - `GEMINI_API_KEY` = আপনার Gemini key
   - `DASHBOARD_PASSWORD` = আপনার পছন্দের শক্ত পাসওয়ার্ড
3. **Volume যোগ করুন (খুব জরুরি):** **+ New → Volume** → সার্ভিসের সাথে যুক্ত করুন → Mount path: `/data`
   (এটা না দিলে প্রতি Deploy-এ WhatsApp লগআউট হবে এবং সব মেমোরি মুছে যাবে।)
4. সার্ভিসের **Settings → Networking → Generate Domain** চাপুন। ওই লিংকই আপনার পেজ।

## ধাপ ৩: একবারের কাজ
লিংকে ঢুকে পাসওয়ার্ড দিন, ফোনে WhatsApp → লিঙ্কড ডিভাইস → ডিভাইস লিঙ্ক করুন → QR স্ক্যান করুন। ব্যস, এরপর আর কিছু করতে হবে না।

## এরপর যা নিজে নিজে হয়
- লিঙ্ক করার পর WhatsApp যে পুরনো চ্যাট পাঠায়, সহকারী সেখান থেকে আপনার কথার ধরন শেখে। নতুন চ্যাট থেকেও শিখতে থাকে।
- আপনি ১৫ মিনিট WhatsApp-এ কিছু না লিখলে বা কোনো চ্যাট না পড়লে সহকারীকে অফলাইন ধরে উত্তর দেওয়া শুরু করে।
- আপনি ফিরে এসে কোনো চ্যাটে লিখলে সেই চ্যাটে সহকারী থেমে যায়।
- শুধু ব্যক্তিগত চ্যাটে, এবং যাদের সাথে আপনি আগে নিজে কথা বলেছেন তাদেরকেই উত্তর দেয়।
- টাকাপয়সা, ব্যক্তিগত বা জরুরি বিষয়ে উত্তর না দিয়ে পেজে "অপেক্ষায়" তালিকায় রাখে।
- প্রতিটি উত্তরের নিচে `This reply is made by AI.` থাকে।
- পেজের সুইচ দিয়ে যেকোনো সময় সহকারী বন্ধ করা যায়।

## জেনে রাখুন
- এটি WhatsApp-এর অননুমোদিত পদ্ধতি, তাই অ্যাকাউন্ট সীমিত বা ব্যান হওয়ার ঝুঁকি আছে।
- চ্যাটের লেখা উত্তর তৈরির জন্য Google Gemini-তে পাঠানো হয়।
